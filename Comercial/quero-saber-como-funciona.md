Nós temos uma API para automatizar a emissão de notas. 

Falando um pouco sobre, ela é padrão REST e possibilita a automatização nos mais variados tipos de sistemas. De forma resumida, a emissão consiste em seu sistema enviar os dados da nota através de um arquivo JSON via requisição https. Dessa forma nossa API vai comunicar com a prefeitura/sefaz e retornar a seu sistema um link com o xml e espelho da nota.

Sendo assim, para trabalhar conosco além do sistema é necessário ter um programador que realize a integração entre o sistema e a nossa solução.

A documentação está nesse link: https://doc.focusnfe.com.br
